# 🌍 Polyglot Examples

"Hello World" style projects demonstrating idiomatic code across Go, TypeScript, Python, and Node.js.

## Projects

Each subdirectory contains a complete project in one language that does the same thing:
**Connect to a Kafka topic, process a message, and store results in a KV store.**

| Language | Directory | Key Concepts Demonstrated |
|----------|-----------|--------------------------|
| **Go** | `go/` | Goroutines, channels, structs, interfaces |
| **TypeScript** | `typescript/` | Types, async/await, classes |
| **Python** | `python/` | Type hints, decorators, dataclasses |
| **Node.js** | `nodejs/` | Event loop, callbacks/promises, modules |

## Quick Start

```bash
# Go
cd go && go run main.go

# TypeScript
cd typescript && npx ts-node main.ts

# Python
cd python && python3 main.py

# Node.js
cd nodejs && node main.js
```

## What You'll Learn

Each project shows:
1. **Configuration** loading (env vars)
2. **Message processing** pipeline
3. **Error handling** patterns
4. **Logging** setup
5. **Data structures** for the domain
